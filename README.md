## Project Overview

An end-to-end ETL pipeline that simulates IoT sensor data from a 3-panel solar farm, transforms it into analytical datasets, loads it into PostgreSQL, and visualizes key energy metrics on a Grafana dashboard.

---

## Pipeline Architecture

```
generate_solar_data.py  →  extract_solar.py  →  transform_solar.py  →  load_solar.py
       (CSV)                  (validate)           (transform)         (PostgreSQL + Excel)
```

---

## Data Source

Simulated IoT CSV data generated by `generate_solar_data.py`:
- **2,160 rows** — 3 panels × 24 hours × 30 days
- **Date range:** 2025-01-01 to 2025-01-30
- **Panels:** Panel_A (18% efficiency), Panel_B (17.5%), Panel_C (19%)

---

## Transformations Applied

| Field | Description |
|---|---|
| `efficiency_pct` | Actual output ÷ theoretical max × 100 |
| `battery_status` | Charging / Discharging / Idle based on net energy |
| `peak_hour_flag` | 1 = peak solar hours (10am–2pm), 0 = off-peak |
| `solar_daily` | Daily aggregates per panel (total kWh, avg efficiency, avg SOC) |

---

## PostgreSQL Schema

**Database:** `solar_db`

- `solar_readings` — 2,160 rows, hourly panel-level readings
- `solar_daily` — 90 rows, daily aggregates (3 panels × 30 days)

## Project Files


## How to Run

```bash
# 1. Install dependencies
pip install pandas numpy psycopg2-binary sqlalchemy openpyxl

# 2. Create the database in psql
CREATE DATABASE solar_db;

# 3. Update your password in load_solar.py
# Change: "password": "your_password"

# 4. Run the pipeline
python generate_solar_data.py
python load_solar.py
```
